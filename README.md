# 役次元 · 画地为牢

**好玩的创意，欢迎一起用。**

这是役次元的单人人体边界挑战游戏。玩家通过手机摄像头画出活动区域，在规定时间内保持身体关节不越界；持续越界或离开画面后，游戏会记录触发事件，并可通过蓝牙连接 EMS 设备输出预设波形。

我们把它开源，让玩家、开发者和同行都能拿去研究、修改，共同创造“自信自爱，方得自由”的役次元社区。

## 玩法

### 画地为牢 · 单人边界挑战

固定手机并确保全身进入画面，使用圈画或矩形工具划定活动区域。游戏开始后，应用会实时识别人体骨骼，并判断肩、肘、腕、髋、膝、踝等关节是否仍在区域内。

玩家可以设置游戏时长、异常持续时间和重复触发间隔。连接兼容的 EMS 设备后，还可以选择设备代际、输出通道、波形和强度。

## 使用流程

1. 授予摄像头权限，固定手机，确保全身进入画面。
2. 选择圈画或矩形，画出活动区域。矩形可拖动四角调整，切换摄像头后需要重新画区。
3. 设置游戏时长、异常持续时间和重复触发间隔。
4. 在 EMS 设备页选择设备代际、通道、波形和强度，并连接设备。
5. 确认电极片已正确接入后开始游戏。
6. 游戏结束后查看本局触发记录，或直接再来一局。

默认游戏时长为 5 分钟，异常持续时间为 3 秒，重复触发间隔为 3 秒。游戏时长支持小数分钟，其余时间使用整数秒。

## 游戏模式

准备页的“游戏模式”菜单保留原有经典安全区，并提供以下玩法：

- **木头人**：提示音乐播放时可以移动，音乐停止后根据骨骼点位移检测身体是否静止；移动和静止时间均可自定义。
- **缩圈模式**：从玩家画出的区域开始，按本局进度平滑缩小到原尺寸的 45%。
- **指定姿势**：随机要求举手、抬腿、下蹲或展开双手，保持成功后得分并更换动作。
- **闪避模式**：摄像头画面中显示往返移动的红色禁区，左右身体碰到时分别记录方向。
- **平衡挑战**：双手展开并单脚站立，结果页记录最长坚持时间。
- **连击模式**：连续完成随机动作累加连击和分数；失败会中断当前连击。
- **双区模式**：画出的区域自动分成 A/B 两区，身体左侧违规强制映射 A 通道，右侧违规强制映射 B 通道。
- **自定义姿势**：在手机上拖动画布中的头、肩、肘、腕、髋、膝、踝，绘制目标火柴人。开始后目标骨架会叠加在摄像头画面中；头、躯干和四肢持续未对齐超过设定秒数时才触发。

木头人右侧的设置按钮可分别调整“音乐可移动时间”和“静止时间”（1 至 60 秒）。打开“每轮随机时间”后，每轮会分别在 1 秒到所设上限之间重新随机。自定义姿势右侧的设置按钮用于编辑火柴人，并可把允许不匹配时间设为 1 至 30 秒。两项设置和自定义骨架都会保存在本机。

经典、缩圈和双区模式需要先画区，其余模式识别到完整人体后即可开始。所有模式共用同一套设备强度上限、Cooldown、急停和断线清零逻辑；得分、连击和缩圈进度绝不会自动提高设备强度。

功能扩展前的稳定版本保存在 Git 分支 `backup/dglab-coyote-v1` 和标签 `dglab-coyote-v1.0.0`，两者均指向提交 `ab64ce7`。

## DG-LAB Coyote 3.0 快速开始

1. 准备好郊狼 3.0、电极片和手机，并在手机上打开最新版 DG-LAB 官方 App。
2. 打开 Yokonex Safety Margin，进入右上角的设备设置。
3. 将输出设备切换为 `DG-LAB Coyote`，点击“连接郊狼”。程序会自动连接官方服务并显示二维码，不需要另外启动服务或输入 IP。
4. 使用 DG-LAB App 扫描二维码，等待页面依次显示“App 已连接”和“已连接”。页面会列出发现的 Coyote 3.0、电量以及 A/B 实时强度。
   如果两款 App 安装在同一台 Android 手机上，可点击二维码下方的“在本机 DG-LAB App 中连接”，无需扫描自己的屏幕。
5. 选择 A、B 或 A+B 通道和波形。首次使用建议保留触发强度 `5`、最大允许强度 `20`、持续时间 `1000 ms` 和 Cooldown `3 s`。
6. 佩戴并确认电极片连接正确后，主动点击“低强度测试”。测试强度最高为 `3`，持续时间最高为 `500 ms`，并受 Cooldown 限制。
7. 保存设置，返回主页并开始 Safety Margin。越界事件会按所选通道和波形发送有限时长的输出。
8. 需要停止时点击红色“立即停止”；游戏运行页也提供红色急停图标。急停会清空 A/B 已执行和排队的任务并把两个通道归零。

连接异常时，先确认手机可以访问网络、DG-LAB App 已连接郊狼 3.0，并让两个设备保持联网。二维码等待超过 5 分钟会由官方服务关闭，点击“重新连接”即可生成新会话。App、设备或 WebSocket 断开后不会自动恢复上一次输出；必须重新连接并确认安全设置。

> 扫码或连接不会触发输出。每次新连接都会先清空任务并将 A/B 强度归零。所有实际输出统一受“最大允许强度”限制，程序不会自动提高强度。

开启“按越界侧映射 A/B”后，左侧监测关节越界发送到 A，右侧发送到 B，两侧同时越界发送到 A+B；无人或遮挡等无法判断侧别的事件仍使用上方选定通道。结果页会显示累计异常时间、最长安全时段以及每次触发的方向和持续时间。

## 判断规则

- 左右肩、肘、腕、髋、膝、踝共 12 个关节参与判断，可信度阈值为 `0.6`，边界上的关节视为区域内。
- 任一可信关节越界，或持续识别不到人，都会开始连续异常计时；两种异常状态互相切换时不会清零。
- 达到异常持续时间后首次触发，异常继续时按照重复触发间隔再次触发。
- 完整识别到人体回到区域内后，异常计时清零。
- 识别到人体但关节不完整，且没有可信越界点时，游戏自动暂停；完整归位后可手动继续。
- 手动暂停、应用进入后台、摄像头故障时，异常计时清零，暂停时间不计入游戏时长。
- 识别流超过 1.5 秒没有新结果时，视为识别中断并暂停游戏。
- 游戏结束优先于同一时刻的设备触发，程序卡顿后不会集中补发触发事件。
- 参数和区域保存在本机，区域与当前摄像头绑定；触发记录仅保留当前一局。

## DG-LAB 实现依据

本项目按照 DG-LAB 官方 `dglab-kit` `1.0.5` 的 V4 Socket 协议实现，核对提交为 `e1707e6e7ef50bdbe8c8dafe19f34289e01dffc0`。应用直接连接官方推荐的 `wss://trex.dungeon-lab.cn/v4`，配对二维码使用官方 `dungeon-lab.cn/s` Socket action 格式；实现覆盖设备快照/增量、临时强度、V3 波形帧、任务清理和连接状态。Flutter 端直接使用 WebSocket，不依赖 Node.js、Python 或独立 bridge。
