# 安全边界：暗黑界面初稿

打开 `index.html` 可并排比较三版；每版均可进入四页交互展示。

## 设置精简

- 首页保留画区、游戏时长、开始。
- 更多设置提供异常持续时间和重复触发间隔，初始均为 3 秒。
- 游戏时长初始为 5 分钟，可选预设或自定。
- 游戏页保留剩余时间、异常倒计时、模拟触发次数、暂停和结束。
- 实际应用的识别规则和已保存参数保持不变。

## 方向

- A：极简黑白，画面与操作明确分区。
- B：沉浸取景，工具贴边，薄荷绿强调操作。
- C：石墨控制台，时长置顶，浅黄色强调操作。

## 演示范围

画区支持自由圈画、矩形、矩形角点调整、重画。切换摄像头会清空区域。
每个屏幕独立运行，可在屏幕外选择人体演示状态。
开始、暂停、继续、结束、再来一局及参数保存可操作。
当前初稿仅用于确认界面方向；真机镜头、姿态推理和设备输出由 Flutter 应用承担。

## 素材

人体画面为 Google MediaPipe 姿态检测文档示例，包含示例骨骼点。
来源：`https://developers.google.com/edge/mediapipe/images/solutions/examples/pose_detector.png`
图标来自现有 Flutter 构建使用的 Material Icons 字体。

## 构建

`node design-demos/build-demos.cjs` 将本地素材内嵌为三个可直接打开的 HTML。
选定方向后，将对应颜色、排版和设置布局应用到 Flutter 界面。
